# Scripts

Automatización prevista:

- levantar/cargar MySQL 8.4.10;
- convertir y validar SQL;
- comprobar fuga entre esquemas;
- ejecutar baseline y adapters;
- calcular EX y categorías de error;
- exportar gráficos, presentación e historial Git;
- auditar el contenido del paquete final.

Cada script deberá aceptar `--help`, fallar con mensajes claros y evitar rutas locales codificadas.
