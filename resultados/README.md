# Resultados

Esta carpeta contendrá artefactos derivados y reproducibles:

- `validacion_propia.csv` obligatorio;
- métricas agregadas en JSON;
- predicciones crudas por corrida;
- curvas de loss en CSV/PNG;
- tiempos, memoria y parámetros entrenables;
- análisis de errores y predicción justificada de EX oculta.

No escribir métricas manualmente. Cada tabla o gráfico del informe debe poder rastrearse a un archivo de esta carpeta.
