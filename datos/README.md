# Datos

| Carpeta | Contenido |
|---|---|
| `entrenamiento/` | Pares aceptados y manifiestos por esquema |
| `validacion/` | Dos esquemas inéditos y 40 preguntas propias |
| `descartes/` | Pares rechazados con motivo auditable |
| `esquemas/` | DDL, datos semilla y metadatos |

No guardar credenciales ni dumps con datos personales. Cada fuente pública debe tener procedencia y licencia. Un ejemplo solo pasa a entrenamiento después de ejecutar correctamente en MySQL 8.4.10.
