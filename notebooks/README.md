# Notebooks

Se mantendrán tres notebooks principales, ejecutables de inicio a fin:

1. `01_datos.ipynb`: adquisición, conversión, traducción, validación y descartes.
2. `02_entrenamiento.ipynb`: baseline, QLoRA A/B, parámetros, tiempos y curvas.
3. `03_evaluacion.ipynb`: EX ponderada, experimento de inferencia y errores.

La lógica reutilizable deberá migrar a módulos o scripts; el notebook documenta y orquesta, no será el único lugar donde exista código crítico.
